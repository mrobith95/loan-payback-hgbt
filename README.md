# loan-payback-hgbt
Basic ML-based loan payback prediction. Originally a kaggle notebook for kaggle playground competition. Medium article for detailed explanation also available [here](https://medium.com/@mrobith95/loan-payback-prediction-using-histogram-gradient-boosting-trees-d93afa7fc961). I also add sequels of that article, namely a [SHAP Tutorial](https://medium.com/@mrobith95/what-i-look-for-when-interpreting-prediction-using-shap-c1685653cb16) and [AI-based explanation](https://medium.com/@mrobith95/turning-rejected-into-understood-using-shap-and-ai-to-humanize-automated-decisions-6a922f0f19de) using the same case study.

The [modelling notebook](https://github.com/mrobith95/loan-payback-hgbt/blob/main/loan_payback_pred.ipynb) mainly focuses on in-depth modelling including feature selection and hyperparameter tuning, while also perform basic analysis routine such as data wrangling and ordinal encoding. [SHAP explaner notebook](https://github.com/mrobith95/loan-payback-hgbt/blob/main/SHAP%20Explainer%20Builder.ipynb) roughly build a SHAP explainer based on trained model.

The rest of files (except gitignore, licence and this readme) used for [prediction web-app](https://huggingface.co/spaces/mrobith95/mr-lpb-0511). The metadata of this web-app can be seen [here.](https://huggingface.co/spaces/mrobith95/mr-lpb-0511/blob/main/README.md)
